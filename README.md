# Shaked Client

**Authors**: Nadav Babai

A web application for shaked company 

### Build, Run Test

- Install dependencies 
```bash
yarn install 
```
- Run Dev:
```bash
yarn dev
```

Update depenecies:

```bash
yarn upgrade-interactive --latest
```
